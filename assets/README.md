# Route map images

Place the two itinerary map images here with these exact names so the guide displays them:

- `malaga-route-map.png` — the "MÁLAGA — REAL STREET MAP ROUTE" image
- `granada-route-map.png` — the "GRANADA — REAL STREET MAP ROUTE" image

The guide (`index.html`) loads them from `assets/malaga-route-map.png` and `assets/granada-route-map.png`.
JPG works too — just rename the files and update the two `<img src="...">` lines in `index.html` to match.
